# commander

Total Commander 스타일의 키보드 중심 듀얼 패널 파일 관리자 (macOS & Windows 지원, Python + PySide6 기반).

## 주요 기능

- **듀얼 패널 & 멀티 탭**
  - 좌우 독립 패널(`Tab` 전환) 및 패널별 멀티 탭(`Ctrl+T` / `Ctrl+W`)
  - 경로 입력창 좌측 드라이브 선택 드롭다운(`C:\`, `D:\`, `/` 등 즉시 전환)
  - 모든 정렬 기준과 방향에서 `..` 상위 폴더 최상단 고정 및 폴더 → 파일 순 정렬
  - 패널 하단 상태 표시줄에 선택 항목 및 전체 항목 개수·용량 실시간 표시
- **키보드 중심 파일 작업**
  - 복사(`F5`), 이동(`F6`), 새 폴더(`F7`), 삭제(`F8`)
  - 작업은 창을 막지 않고 백그라운드에서 동시에 실행되며, 하단 큐 패널에 작업별 진행률·속도·남은 시간과 일시정지/취소 버튼 표시
  - 삭제는 기본적으로 휴지통으로 이동(`F8`), 영구 삭제는 `Shift+F8`
  - 대상에 같은 폴더가 있으면 병합하고, 겹치는 파일만 덮어쓰기 / 건너뛰기 / 둘 다 유지 선택(모두 적용 가능). 일부 항목이 실패해도 나머지는 계속 진행하고 끝에 요약 표시
  - 다중 이름 변경(`F2`) — 이름/확장자 마스크(`[N]`, `[E]`, `[C]` 카운터, 날짜), 찾기→바꾸기(정규식), 대소문자 변환, 실시간 미리보기 및 충돌 방지
  - 내장 뷰어(`F3`) — 크기 제한 없는 텍스트/hex/이미지 보기, 에디터(`F4`) — 1MB 이하 UTF-8 텍스트 편집·저장, Quick View(`Ctrl+Q`)
  - 스트리밍 파일 검색(`Ctrl+F`) — 글롭/부분 문자열 재귀 검색(파일 내용에 포함된 텍스트로도 검색) 및 선택한 결과 폴더로 즉시 이동
- **비교·동기화·검증** (상단 `도구` 메뉴)
  - 폴더 비교, 좌우 나란히 보는 파일 내용 비교
  - 폴더 동기화: 양방향(최신 우선) 또는 한 방향, 실행 전 항목별 검토·수정, 삭제는 휴지통으로
  - 파일 내용 검색(`Ctrl+F`에서 포함 텍스트 지정), 체크섬(SHA-256/SHA-1/MD5) 계산 및 검증
- **사용자 설정** (`Ctrl+,`)
  - 밝게 / 어둡게 / 시스템 테마, 표시할 컬럼 선택, 모든 단축키 재정의
  - 하단 명령줄: 현재 폴더에서 명령 실행, 결과 출력 확인
  - 사용자 정의 도구: 선택한 파일로 외부 프로그램 실행 (메뉴·버튼·단축키)
- **압축 파일 탐색**
  - `zip`, `tar`, `tar.gz`(`tgz`), `tar.bz2`(`tbz2`), `tar.xz`(`txz`) 아카이브를 풀지 않고 폴더처럼 탐색(`Enter` / `Backspace`)
  - 반대편 로컬 패널로 선택한 항목만 추출(`F5`, 경로 탈출 방지 포함)
  - 선택 항목을 새 압축 파일로 만들기(`Alt+F5`)
- **원격 파일 시스템 (FTP / SFTP)**
  - `Ctrl+N`으로 `ftp://[user[:pw]@]host[:port][/path]` 또는 `sftp://[user[:pw]@]host[:port][/path]` 연결
  - 로컬 패널과 동일한 방식으로 탐색 및 업로드·다운로드(`F5`, 재귀 폴더 전송 지원)
- **빠른 폴더 용량 계산 & 영구 캐시**
  - 백그라운드에서 Bottom-up 방식으로 하위 트리 폴더 용량을 한 번의 순회로 동시 계산
  - 계산된 용량을 `~/.config/commander/dir_sizes.json`에 캐싱하여 재방문·재시작 시 0ms 즉시 표시 (파일 복사/이동/삭제 시 관련 경로 자동 무효화)
- **세션 상태 자동 저장·복원**
  - 창 크기·위치, 스플리터 비율, 패널별 탭 목록·경로, 정렬 컬럼·방향, 숨김 파일 표시 여부, 커서 및 선택 항목, 즐겨찾기를 `~/.config/commander/state.json`에 자동 보존 (사용자 설정은 `settings.json`)
- **GitHub Releases 기반 자동 업데이트**
  - 앱 시작 시 백그라운드 자동 확인 및 상단 **도움말 > 업데이트 확인...** 메뉴 지원
  - 새 릴리스 발견 시 OS별 패키지(`commander.zip` / `commander-win64.zip`)를 자동 다운로드하여 기존 앱을 교체하고 새 버전으로 즉시 재실행

## 단축키

모든 단축키는 `도구 > 설정... > 단축키`에서 바꿀 수 있습니다. 아래는 기본값입니다 (macOS에서는 `Ctrl` 대신 `Cmd`).

| 단축키 | 동작 |
| --- | --- |
| `Tab` | 좌 / 우 패널 전환 |
| `Enter` / 더블클릭 | 폴더, 압축 파일 진입 또는 파일 실행 |
| `Backspace` | 상위 폴더로 이동 (압축·원격 루트에서는 로컬로 복귀) |
| `Space` / `Insert` | 현재 항목 선택 토글 후 다음 행으로 이동 |
| `Ctrl+T` (`Cmd+T`) | 현재 패널에 새 탭 열기 |
| `Ctrl+W` (`Cmd+W`) | 현재 탭 닫기 |
| `Ctrl+F` (`Cmd+F`) | 하위 폴더 재귀 파일 검색 |
| `Ctrl+N` (`Cmd+N`) | FTP / SFTP 원격 서버 연결 |
| `Ctrl+H` / `Ctrl+.` (macOS는 `Cmd+.`) | 숨김 파일(`.*`) 표시 토글 |
| `Ctrl+L` | 하단 명령줄로 이동 (현재 폴더에서 명령 실행, `cd` 지원) |
| `Ctrl+,` | 설정 (테마, 컬럼, 단축키, 사용자 도구) |
| `Ctrl+S` | 빠른 필터 (텍스트 또는 `*.txt;*.md`, `Esc`로 해제) |
| `Alt+←` / `Alt+→` | 방문한 폴더 뒤로 / 앞으로 |
| `Ctrl+D` | 폴더 즐겨찾기 메뉴 (이동·추가·제거) |
| `+` / `-` / `*` | 패턴으로 선택 / 선택 해제 / 선택 반전 |
| `Ctrl+Shift+C` | 선택 항목(없으면 현재 폴더) 경로 복사 |
| `Shift+F2` | 폴더 비교 — 양쪽 패널에서 다르거나 한쪽에만 있는 항목 선택 |
| `Ctrl+Shift+S` | 폴더 동기화 (비교 → 검토 → 실행) |
| `Ctrl+Shift+D` | 파일 내용 비교 (좌우 나란히, `F3`/`Shift+F3`로 차이 이동) |
| 우클릭 | 컨텍스트 메뉴 (열기, 경로 복사, Finder/탐색기에서 보기, 터미널 열기 등) |
| 드래그 앤 드롭 | 반대편 패널·폴더 또는 외부 앱에서 끌어다 놓아 복사 (`Shift`는 이동) |
| `F2` / `Ctrl+M` | 다중 이름 변경 (마스크·카운터·찾기/바꾸기·대소문자, 미리보기) |
| `Alt+F5` | 선택 항목을 압축 파일로 만들기 (zip, tar, tar.gz, tar.bz2, tar.xz) |
| `Ctrl+B` | 평면 보기 — 하위 폴더의 모든 파일을 한 목록에 표시 |
| `F3` | 내장 파일 뷰어 — 텍스트 / hex / 이미지, 대용량 파일 지원 (뷰어 안에서 `F3`: hex 전환) |
| `Ctrl+Q` (macOS `Control+Q`) | Quick View — 반대편 패널 자리에 커서 아래 파일 미리보기 |
| `F4` | 내장 텍스트 에디터 (1MB 이하 UTF-8 편집·저장) |
| `F5` | 반대편 패널로 복사 / 압축 추출 / 원격 업로드·다운로드 |
| `F6` | 반대편 패널로 이동 |
| `F7` | 새 폴더 만들기 |
| `F8` / `Del` / `Ctrl+Backspace` | 선택 항목을 휴지통으로 이동 |
| `Shift+F8` / `Shift+Del` | 선택 항목 영구 삭제 |

## 설치 및 실행

### 1. 릴리스 설치 (macOS / Windows)
[Releases](https://github.com/sungback/commander/releases) 페이지에서 운영체제에 맞는 최신 패키지를 다운로드합니다:
- **macOS**: `commander.dmg` 또는 `commander.zip` 다운로드 후 `commander.app`을 `/Applications`에 복사해 실행
- **Windows**: `commander-win64.zip` 다운로드 및 압축 해제 후 `commander/commander.exe` 실행

### 2. 소스에서 실행
Python 3.11 이상이 필요합니다.

```sh
git clone https://github.com/sungback/commander.git
cd commander
python3 -m venv .venv
. .venv/bin/activate
pip install -e ".[dev]"

# 소스 직접 실행
./scripts/run.sh
```

### 3. 패키징 빌드 (macOS / Windows)
```sh
pip install pyinstaller

# macOS (.app / .dmg / .zip 생성 및 /Applications 설치)
./packaging/build_mac.sh

# Windows (dist/commander-win64.zip 생성, PowerShell)
pwsh ./packaging/build_win.ps1
```
